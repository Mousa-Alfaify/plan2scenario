## التشغيل

```bash
npm install
npm run dev
```

ثم افتحي `http://localhost:5183`

للبناء الإنتاجي:

```bash
npm run build
npm run preview
```

مخرجات البناء في `dist/` (تعمل عبر أي خادم ملفات ثابت).

## الحفظ

كل شيء يُحفظ محليًا في `localStorage` تحت المفتاح `pts-academy-v1`:
التقدم، نتائج الاختبارات، المشاريع، الجداول، النماذج.

نموذج البيانات في `src/store/types.ts` مصمم ليكون قابلاً مستقبلاً للربط بحساب مستخدم على Backend:
كل كيان له `id` مستقل وطوابع زمنية، والمشروع وحدة مغلقة قابلة للتصدير JSON.

---

## الخط

يستخدم النظام **خط ثمانية** (Thmanyah Sans) بأوزانه الخمسة، و Thmanyah Serif Display للعناوين البارزة.
ملفات الخط مضمّنة في `public/fonts/` فلا حاجة لاتصال بالإنترنت.

## النشر

الموقع منشور عبر **GitHub Pages** من فرع `main` ومجلد `/docs`:

**https://mousa-alfaify.github.io/plan2scenario/**

لإعادة النشر بعد أي تعديل — أمر واحد:

```bash
npm run build && touch docs/.nojekyll && cp docs/index.html docs/404.html && git add -A && git commit -m "تحديث الموقع" && git push
```

> `npm run build` يُخرج إلى `docs/` مباشرة (مضبوط في `vite.config.ts`)، والمسارات نسبية
